# План исследования: возникновение CA1–PFC communication subspace в обучаемой спайковой сети

Статус: черновой план (v1), дата составления: 2026-10-15.
Кандидат №1 из обсуждения (см. предыдущий research-отчёт в сессии Claude Code).

---

## 1. Формулировка исследовательского вопроса

**Эмпирический факт, который мы объясняем** (Hippocampal-Prefrontal Communication Subspaces Align with Behavioral and Network Patterns in a Spatial Memory Task, eNeuro, 2025, PMID 40854711):
у крыс в задаче на пространственную память поведение лучше всего предсказывается не локальной активностью CA1 или PFC по отдельности, а общим низкоразмерным **коммуникационным подпространством** между ними (reduced-rank regression, кольцевая геометрия многообразия). Осцилляторное состояние сети и скорость движения модулируют структуру и "качество" этого подпространства.

**Методологическая основа** (Semedo et al. 2019, Neuron, "Cortical Areas Interact through a Communication Subspace", PMID 30770252): communication subspace определяется через reduced-rank regression (RRR) между одновременно записанными популяциями — находится ранг r, при котором линейная проекция активности региона A предсказывает активность региона B с максимальной кросс-валидационной точностью; "подпространство" — это сами предсказывающие направления (compared against the full-rank / unregularized regression и against a random-direction baseline).

**Вопрос:** возникает ли low-rank коммуникационное подпространство между двумя спайковыми популяциями **как естественное следствие обучения по Хеббу (STDP)** на структурированной последовательной задаче, и управляется ли его "качество" (ранг, предсказательная сила) тета-подобной осцилляторной модуляцией — так же, как это наблюдается экспериментально?

**Почему это даёт научную новизну:** проверено (PubMed: `"communication subspace" AND (spiking neural network OR computational model)` → 0 результатов; arXiv: только reduced-rank-regression туториал и одна близкая, но не идентичная rate-RNN работа "Structure of activity in multiregion recurrent neural networks", 2024, без спайков и без пластичности). То есть никто ещё не показал **механистически**, из какой динамики (STDP + осцилляции) возникает это явление — есть только его описание на реальных данных (eNeuro 2025) и его формализация как статистического метода (Semedo 2019). Мы были бы первыми, кто связывает оба конца этой цепочки вычислительной моделью.

## 2. Конкретные, фальсифицируемые гипотезы

- **H1 (возникновение):** в двухрегиональной спайковой сети со STDP на межрегиональных синапсах, обученной на структурированной последовательности входов, предсказательная сила RRR между регионами на оптимальном ранге r* значимо выше, чем в сети без обучения (случайные веса, та же архитектура) и выше, чем ожидается от общего входного драйва (shared-input null model, см. §5).
- **H2 (низкая размерность):** оптимальный ранг r* << min(N_CA1, N_PFC) (т.е. подпространство действительно низкоразмерно, а не "вся активность целиком").
- **H3 (осцилляторная модуляция):** добавление тета-подобной (4-8 Гц аналог) ритмической модуляции возбудимости повышает предсказательную силу RRR и/или меняет r* по сравнению с тем же обучением без ритма — направление эффекта берём из эксперимента (осцилляции улучшают коммуникацию) как основную гипотезу, но фиксируем и альтернативу "осцилляции меняют геометрию, не обязательно силу".
- **H4 (связь с поведением):** в сети, которой приходится дать "решение" на основе CA1→PFC сигнала (аналог T-maze/спатиал-задачи), точность решения коррелирует с силой/рангом коммуникационного подпространства по триалам сильнее, чем с суммарной firing rate любого из регионов отдельно.
- **H5 (геометрия, опциональная/исследовательская):** оценить, возникает ли в проекции на подпространство кольцевая/циклическая структура (как в реальных данных) при периодической структуре задачи — это более рискованная, "exploratory" часть, не являющаяся обязательным условием публикуемости статьи.

## 3. Архитектура модели

### 3.1 Нейронная модель
- LIF или AdEx (адаптивный экспоненциальный LIF) в Brian2 — AdEx предпочтительнее, т.к. даёт более реалистичную адаптацию частоты разряда, которая нужна для правдоподобной модуляции скоростью/возбудимостью (аналог "speed modulates communication subspace" из эксперимента).
- Внутри каждого региона: баланс E/I (80/20), случайная разреженная связность (~10-15%), давая каждому региону собственную рекуррентную динамику (не просто relay).

### 3.2 Два региона
- **CA1-аналог** (N≈200-400 нейронов): получает последовательный "сенсорный" вход — паттерны, кодирующие позицию/контекст в упрощённом линейном треке (аналог "place cell"-подобного кода, НЕ полноценная attractor-модель — это не предмет статьи).
- **PFC-аналог** (N≈200-400 нейронов): получает вход только через межрегиональные синапсы от CA1-аналога + собственный рекуррентный драйв; его выходная активность в конце триала используется для "решения" (readout, см. §3.5).

### 3.3 Межрегиональная связь
- Разреженная (~5-10% связности) feedforward CA1→PFC, опционально слабая feedback PFC→CA1 (для второй статьи/расширения — не обязательно в MVP).
- **STDP** на этих синапсах (pair-based, как уже обосновано в вашем `Анализ_фреймворков_SNN.txt`), с биологически правдоподобным окном (~20 мс).
- Условие сравнения: "обученная" сеть (после N эпох триалов со STDP) vs "наивная" (случайные веса той же статистики, STDP выключен) — это прямой тест H1.

### 3.4 Осцилляторная модуляция (тест H3)
- Общий тета-пейсмейкер (4-8 Гц), модулирующий возбудимость (ток смещения) нейронов CA1-аналога и/или PFC-аналога с управляемым фазовым сдвигом между регионами — именно фазовое соотношение, а не просто наличие ритма, важно воспроизвести как переменную эксперимента.
- Условия: без ритма / синфазный ритм / ритм со сдвигом фазы — три уровня для статистического сравнения.

### 3.5 "Поведенческая" задача (тест H4)
- Упрощённый аналог: последовательность из 2-4 "позиционных" input-паттернов в CA1-аналог за триал (аналог прохода по треку), затем "развилка" — PFC-аналог должен в конце триала иметь более высокую активность в одной из двух выходных суб-популяций в зависимости от того, какая последовательность была предъявлена (аналог left/right выбора в T-maze).
- "Точность" = доля триалов, где активность корректной выходной суб-популяции PFC выше альтернативной.
- Это самый упрощённый компонент плана и первый кандидат на дальнейшее усложнение, если потребуется для журнала с более высокими требованиями к поведенческому правдоподобию.

## 4. Протокол генерации данных

1. **Этап A — предобучение:** N_train триалов (порядок 500-2000, подобрать эмпирически по сходимости весов) со STDP включённым, без записи "экспериментальных" данных — только для формирования устойчивых межрегиональных весов.
2. **Этап B — запись:** N_test триалов (порядок 200-500) с фиксированными (замороженными) весами — имитация "сессии записи" в реальном эксперименте, чтобы не путать эффекты онлайн-обучения с структурой уже сформированного подпространства.
3. Повторить A+B для каждой комбинации условий: {обучено / наивно} × {без ритма / синфазный / со сдвигом фазы} → минимум 6 полных прогонов, с несколькими случайными seed'ами (≥10) на комбинацию для статистики по сетям, а не только по триалам.
4. Для каждого триала сохранять: спайковые растры обоих регионов (SpikeMonitor), бинированные частоты (например, окна 10-20 мс), итоговое "решение" PFC.

## 5. Аналитический конвейер

1. **Reduced-rank regression** между бинированной активностью CA1-аналога (предиктор) и PFC-аналога (отклик) по методологии Semedo et al. 2019: кросс-валидация по рангу r = 1…min(N)-1, выбор r*, сравнение предсказательной силы (R²/variance explained) с:
   - **Full-rank regression baseline** (обычная линейная регрессия без ограничения ранга) — проверка, что low-rank не просто "вся регрессия хуже".
   - **Shared-input null model**: регрессия между двумя случайными подвыборками самого PFC-аналога (половина нейронов предсказывает другую половину) — контроль на тривиальный общий вход/коррелированный шум, а не настоящую межрегиональную коммуникацию.
   - **Shuffle-triаl null**: та же RRR, но с перемешанными по триалам парами CA1↔PFC — разрушает временную/триальную структуру, оставляя только средние статистики.
2. **Валидация метода на известной связности** (дополнительный, более "методический" вклад статьи): поскольку мы полностью контролируем истинную connectivity, можно явно показать, что RRR корректно восстанавливает направление и силу известной нам связи при вариации плотности/STDP — это важный sanity-check, который в реальных данных сделать нельзя (там связность неизвестна), а у нас — можно, и это самостоятельно публикуемый методический результат.
3. **Снижение размерности и визуализация геометрии** (для H5): PCA/UMAP/Isomap на проекции в коммуникационное подпространство, визуальный и количественный (например, через circular statistics) поиск кольцевой структуры.
4. **Статистика:** смешанные линейные модели (условие × seed как случайный эффект) для сравнения r*/R² между условиями; permutation-тесты для сравнения с null-моделями.

## 6. Ограничения, которые нужно явно проговорить в статье

- Модель — намеренное упрощение (точечные нейроны, упрощённая "задача"), не претендует на анатомическое соответствие CA1/PFC — это следует явно заявить как scope statement, а не скрывать.
- Временные масштабы (теta 4-8 Гц, STDP-окно ~20 мс) взяты из общей литературы, не откалиброваны по конкретным данным крысы из eNeuro-2025 — при наличии доступа к их данным (стоит написать авторам или поискать публичный датасет) можно было бы откалиброваться точнее — указать как future work.
- "Поведенческая задача" — абстракция, а не полноценная модель T-maze/навигации — если рецензент потребует больше правдоподобия, это главное направление доработки.

## 7. Стек реализации

- **Симуляция:** Brian2 (уже проверен в проекте), STDP через `Synapses(..., on_pre=..., on_post=...)`.
- **RRR/статистика:** можно написать вручную (несложно — сингулярное разложение коэффициентов обычной ridge-регрессии, см. Semedo 2019 Methods) или использовать существующий код, если авторы Semedo 2019/туториала 2025 выложили его в открытом доступе (проверить на их lab GitHub — не проверялось в этой сессии).
- **Статистика/визуализация:** `scikit-learn` (ridge regression, PCA), `statsmodels` (mixed models) или `pingouin`, `umap-learn` для H5.
- Все эти зависимости легко ставятся на Windows (чистые Python-пакеты, без проблем, аналогичных NEST/NEURON).

## 8. Поэтапный план работ (milestones)

| Этап | Содержание | Критерий готовности |
|---|---|---|
| M1 | Односторонняя сеть: один регион, базовая AdEx + STDP, sanity-check (firing rates в физиологичном диапазоне, STDP действительно меняет веса ожидаемым образом) | Код запускается, веса сходятся, нет патологической активности (silence/эпилептиформный разряд) |
| M2 | Два региона, статическая (не обучаемая) связь. Валидация RRR-метода на известной связности (пункт 5.2) | RRR корректно восстанавливает заданную связность на синтетических данных |
| M3 | Включить STDP на межрегиональных синапсах, сравнить "обучено" vs "наивно" (тест H1, H2) | Статистически значимая разница в R²/r* между условиями, воспроизводится на ≥10 seed'ах |
| M4 | Добавить тета-модуляцию и фазовый сдвиг (тест H3) | Направленный эффект ритма на коммуникационное подпространство, статистически устойчивый |
| M5 | Добавить "поведенческую" развилку и readout (тест H4) | Корреляция точности решения с силой подпространства по триалам |
| M6 | (опционально, exploratory) Геометрия многообразия, тест H5 | Любой результат — даже отрицательный ("кольца не возникает") — информативен и обсуждаем в статье |
| M7 | Финальные прогоны для всех фигур + статистика + черновик рукописи | Все фигуры воспроизводимы из одного скрипта/notebook, seed зафиксирован |

Реалистичная оценка: M1-M3 — основной технический риск и основная часть времени; M4-M6 — инкрементальные расширения поверх готового пайплайна.

## 10. Главные риски и как их снижать

| Риск | Снижение |
|---|---|
| STDP не сходится к осмысленной структуре, а просто насыщает/обнуляет веса | Стандартный STDP с ограничением весов (hard/soft bounds), контроль по журналу синаптических весов во время предобучения (M1) |
| Эффект осцилляций статистически слаб/не воспроизводится между seed'ами | Заранее заложить ≥10 seed'ов на условие, а не 1-2 — иначе статья получит именно эту претензию от рецензента |
| RRR-результат объясняется тривиальным общим входом, а не "коммуникацией" | Обязательные null-модели из §5.1 — без них результат не публикуем, это ключевая методологическая защита от главной критики, которую получают такие статьи |
| "Поведенческая задача" слишком абстрактна для рецензента нейронаучного журнала | Либо явно позиционировать статью как "proof-of-concept механизма", либо (если будет время) синхронизировать параметры с реальным eNeuro-2025 датасетом, если он публичный |
